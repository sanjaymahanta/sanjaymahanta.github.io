GitOps RAG
Validation Pipeline

Automated CI/CD validation for RAG systems using Giskard and Gemini 2.5 Flash

Introduction

Built an automated GitOps pipeline using GitHub Actions to continuously validate Retrieval-Augmented Generation (RAG) systems. The pipeline intercepts model iterations and prevents hallucinated or ungrounded responses from reaching production.

By integrating Giskard's LLM evaluation framework with the Google Gemini 2.5 Flash model acting as an autonomous evaluator, this CI/CD pipeline enforces strict quality gates on AI outputs.

Key Features

  1. LLM-as-a-Judge Evaluation: Uses Gemini 2.5 Flash as an autonomous evaluator to analyze the RAG system's responses against source context.
  2. Giskard Integration: Leverages the Giskard open-source framework to generate standardized test suites for LLM outputs.
  3. Hallucination Detection: Specifically tests for ungrounded hallucinated facts that the RAG model may invent outside of the provided context.
  4. Automated CI/CD Quality Gates: Integrated directly into GitHub Actions. If the evaluator detects hallucinations or poor retrieval, the build fails and deployment is halted.

How the Pipeline Works

Testing LLMs in production requires moving beyond standard unit tests. Because LLM outputs are non-deterministic, traditional assertions often fail. This project uses "LLM-as-a-Judge" mechanics, where a secondary, highly-capable model evaluates the output of the primary RAG system. If the secondary model determines the output is hallucinated, the CI pipeline throws a status failure, preventing the new AI iteration from going live.

Technology Stack

  • Python
  • Giskard LLM Evaluation Framework
  • Google Gemini 2.5 Flash API
  • GitHub Actions (CI/CD)
  • Retrieval-Augmented Generation (RAG)

Workflow

  1. Code/Prompt update pushed to GitHub
  2. GitHub Actions pipeline triggers
  3. RAG System generates answers to test queries
  4. Giskard invokes Gemini 2.5 Flash evaluator
  5. Evaluator scores the answers for hallucinations
  6. If hallucination detected -> Pipeline FAILS
  7. If answers grounded -> Pipeline PASSES
