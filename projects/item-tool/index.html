Project Overview

Worked on an enterprise IT management application where I collaborated with two product modules: Ticket and Asset.

The application required continuous functional testing across multiple modules. I worked closely with the respective teams to understand requirements, execute testing and automate repetitive test scenarios.

Automation Framework

I developed a Java and Selenium based automation framework to automate repetitive functional and regression test scenarios.

As the number of test cases increased, executing them sequentially became inefficient. To solve this, I introduced Selenium Grid with Docker so that multiple test cases could execute in parallel.

Execution Architecture

  1. Test cases are written using Java and Selenium.
  2. Automation framework prepares the test execution.
  3. Tests are sent to Selenium Grid.
  4. Docker provides isolated browser execution environments.
  5. Multiple tests can execute in parallel.
  6. Test execution can be performed on a remote machine.

Dockerized Selenium Grid

I used Docker to create a repeatable Selenium Grid environment for browser automation.

This made it possible to run automation tests in parallel across browser nodes instead of depending only on local browser execution.

CI/CD Integration

The automation framework was integrated with Jenkins so that test execution could be triggered through a CI/CD pipeline.

  • Source code maintained using Git.
  • Jenkins used for automated execution.
  • Maven used for build and dependency management.
  • Selenium Grid used for parallel execution.
  • Docker used for the browser execution environment.

BrowserStack Integration

A client requirement required the existing automation test cases to execute on BrowserStack.

I quickly learned the required BrowserStack integration and successfully connected the existing framework with the cloud execution platform through the Jenkins pipeline.

LambdaTest Integration

I also integrated LambdaTest with the automation framework to support cloud-based browser execution.
