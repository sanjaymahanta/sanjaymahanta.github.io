Autonomous Selenium Automation with AI-Powered Locator Recovery

Introduction

Built an AI-powered self-healing automation framework using Java, Selenium, and Google Gemini 2.5 Flash to reduce test maintenance caused by broken and flaky locators.

The framework automatically detects locator failures, analyzes the live DOM, asks the LLM to identify a better locator, validates the result using a confidence score, and continues execution without requiring manual locator updates.

Key Features

  1. Intent-Based Testing: Instead of relying only on brittle XPath expressions, the framework can use natural-language intent such as "The orange login button". The AI uses the available page information and DOM structure to identify the appropriate element.
  2. CSS Selector Optimization: The framework uses CSS selectors for improved performance and compatibility with modern JavaScript-heavy applications and Shadow DOM scenarios.
  3. AI-Powered Self-Healing: When an existing locator fails, the framework intercepts the failure and analyzes the live DOM to identify an alternative locator.
  4. Confidence Score: The LLM provides a confidence score from 0-100 for the proposed healed locator. The framework uses this score to help ensure that the AI-generated locator is reliable before continuing execution.
  5. Seamless Recovery: The framework automatically detects the failure, analyzes the DOM, generates a replacement locator and attempts recovery during test execution.

How Self-Healing Works

Test maintenance is one of the most time-consuming aspects of UI automation. When developers change UI elements, static locators often break, causing false-positive test failures. This project focuses on solving test-maintenance and flaky-locator problems using Java, Selenium and Google Gemini 2.5 Flash.
